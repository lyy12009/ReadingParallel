## 每案共用的完整流程

每個案例都完成以下步驟，不能只看表格達標。

- [ ] 選冊課及來源，確認整課生詞候選未被來源縮限，按該案指定選詞／手動詞／最低值。
- [ ] 第一階段核對不同詞數、最低總詞次、各格要求與篇幅；區分A格式問題、B待教師評估、C無法自動判定。確認無任意「一定衝突」結論。
- [ ] 展開並複製生成提示詞，確認原文、篇數、字數、人物、語法、已學範圍、新情節與次數仍在；本次可用固定文本代替外部LLM。
- [ ] 貼初始文本，按「執行 Python 檢測」，對照該案表格；閱讀疑似超綱及證據，勿以舊版彙總當正式結果。
- [ ] 必要修訂後重新貼回，確認舊檢測／修訂提示失效；重新檢測；教師另外審查故事、詞義、語法與自然度。
- [ ] 核對保留詞與補充解釋；不能為了消除警告把全部未知詞加允許清單。若樣本不適合課次，記「待決／退回修訂」。
- [ ] 教師核准可用稿才按「將目前檢測內容確認為定稿」。為驗證C的技術下游可模擬此按鈕，但另記「歧義未裁決」，不簽為教學達標。
- [ ] 第三階段檢查定稿正文不變、題型／題數及補充語言正確；固定JSON只驗流程，不代表LLM實際產生相同品質。
- [ ] 將該案quiz.json全文貼入第四階段，按「解析 JSON 並填入以下編輯區」。核對篇數／正文／三題／A-B-C答案與題目證據，不只核對沒有解析錯誤。
- [ ] 查看「自動檢測異常」及選用完整逐題表；題幹、選項與說明的疑似超綱應可見，補充語言解釋皆有。固定樣本仍有未處理項，不應宣稱全部超綱已解決。
- [ ] 在作答說明末尾暫加「獨角獸太空港。」確認題目詞彙提示更新，記錄後刪除；這不是正文重檢功能。
- [ ] B/C核對禮物／豆的兩語解釋，切換「在學生版及教師版列印補充生詞」，確認兩版同步顯示／隱藏，再恢復列印。釋義是否適合學生由教師決定。
- [ ] 下載學生／教師Word並開啟：正文與題目完整，只有教師版有答案，字型／A4／分頁／長選項／多語內容可讀。程式讀回檢查不代替此視覺驗收。
- [ ] 最後提高一格最低值：摘要更新、last_audit與核准失效，草稿／教師意見／已編輯Word正文保留；不能沿用原定稿狀態。

### 所有案例都要注意的Word編輯缺口

在獨立測試副本中，可於第四階段正文末尾加入「獨角獸太空港。」觀察：目前**不會**自動重新正式檢測正文，也不撤銷第二階段核准。這是已重現的IA-01，不是驗收通過條件；不要輸出給學生。復原測試文字。實際要修改正文時，先另存編輯稿，再回第二階段重檢與定稿，重新核對／產生命題並載入；先前題目不保證仍適用。
