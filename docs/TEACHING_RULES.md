## 三、目前功能流程與判定細節

### 教材、已學詞彙與目標詞

[app.py](../app.py):91 定義四個文本部分。選課保留 DATA 的全域索引 idx（785–788行），並不在切換冊別時清空先前冊的已學集合。get_lexicon() 使用歷課含本課的生詞聯集；來源文本的 target 則是 words(lesson, [reference])（841行），所以「當次目標」不等於整課生詞，也不等於所有已學詞。

curriculum_evidence() 累積全課文斷詞及語法欄位全形冒號後文字；沒有冒號者不提供語法斷詞證據。「貴姓」另有硬編碼加入。課文片段用於連續用詞比對。

### 人名與斷詞

build_tokenizer():26 優先使用根目錄 dict.txt.big，其次 dictionaries/dict.txt.big；清理格式後寫暫存檔，少於1,000筆有效詞條或初始化失敗時回退預設字典。格式檢查及初始化不等於教學正確性。dictionaries/teaching_words.txt 僅在存在時載入；本基準未提供此檔。

names_from_dialogue():187 讀行首1–8字元的冒號標籤；explicit_names_from_source():199 用「我是、我叫、這是」句型產生候選，可能把「老師」等非姓名誤列。speaker_warnings():250 只核對教師核准清單，且介面只在「對話」模式呼叫（882行）。cleanbody():153 去除部分標題及行首最多12字的冒號前綴，可能同時刪除一般敘述前綴。

audit() 對教材／核准集合中的多字詞先做最長比對，剩餘片段交 Jieba，HMM=False。不使用詞性或通用人名辨識模型。即使註解強調避免用已學單字拼新詞，也不能由此保證所有複合詞都不漏報。

### 複現、超綱與相似度

audit() 的 baseline 是已學生詞、教師允許詞、課文證據、語法證據、核准人名之聯集；另有固定功能字集合。計數分類依序為核准人名、已學生詞、語法例句、課文斷詞／連續子字串、教師允許詞、功能字，剩餘列「疑似超綱」。分類先後只決定顯示證據，不代表教師訂定的學習程度排名。

多字 token 若為任一歷來課文／語法片段的子字串，也可視為課文證據。未含漢字的 token 不計入超綱詞次。目標詞以清理正文中的非重疊子字串計次；例如「是不是學生」對「是」計2次，與語言學獨立詞次不等同。

覆蓋概念為「出現至少一次的目標詞項數／目標詞項數」，次數表則逐詞列次數，重複出現不能增加覆蓋分子。空目標集合的百分比語意尚待確認。當前只彙總全部貼入內容。60%／80% 是現行介面與提示詞選項，不能取代本次已確認的每詞每篇最低次數；是否保留額外百分比門檻仍待Q04。

ngram_overlap():167 與 SequenceMatcher 提供連續8漢字重合及字元相似度；899行的0.25／0.7只觸發提醒，不能判斷情節是否新穎或構成語意抄改。count_han():163 只數清理後漢字，不數英數標點。901行以單篇下限及 n 倍上限檢查總字數，不是逐篇檢查。

### LLM 提示詞與教師定稿

- prompt1（861–872行）：產生1–3篇對話／短文提示詞，包含來源、目標生詞／語法、字數、人物、引導詞及覆蓋需求；沒有附完整累積詞庫。
- prompt2（926–935行）：以 Python 檢測線索與教師意見建議修訂，排除教師保留詞；仍由外部 LLM 處理。
- prompt3（973–992行）：以 final_text 命題，附累積詞庫、允許詞、多語釋義、文字差異線索；要求先內容、再語言自檢並輸出 JSON。
- compare_changes():320 只提供文字差異，不證明情節或事實差異。quiz_revision_prompt():583、inspect_questions():519 目前未接到主介面呼叫，不視為正在執行的獨立修題流程。
- 942行確認定稿要求文本、人名、引導詞仍與檢測快照相同，並無未核准說話者。第三階段受 approved 控制，但第四階段可直接貼 JSON。

### 閱讀測驗、JSON 與補充詞

parse_learning_json():603 檢查文本、title/type、題幹、選項陣列、答案等型別；可接受 Markdown 包裹 JSON。JSON 欄位包括 title、reading_texts、supplementary_vocabulary、instructions、questions、validation_warnings。型別通過不等於內容正確。

inspect_structured_quiz() 檢查題數、題型、單選四個非空且文字不同的選項及 A–D 答案等；不判斷四個不同文字是否同義正解。支援 single_choice／true_false／short_answer／ordering；混合題型沿用各題 type。

normalized_glossary() 同詞合併來源 reading/question 與多語解釋；同語言不同非空解釋後者覆蓋前者。missing_glossary_explanations() 只驗非空，不驗翻譯。json_to_editors():668 轉為可編輯純文字後，editable_quiz_checks():768 只補基本題數、選項數及答案項數。split_items():508 有至少3字元的題幹條件，可能漏計短題幹。

quiz_vocab_review() 先用基本允許集合檢查，再加入補充詞檢查，比較「已由補充生詞涵蓋」與「尚未解決」。它不以釋義是否完整或是否列印為條件；保留詞不是永久升級為已學詞。

### Word 輸出

write_docx() 以 BytesIO 產生 A4 docx，設定 Microsoft JhengHei、標題、正文、生詞及測驗；短選項可兩欄，教師答案有內容時另頁。第四階段可編輯正文與答案，並勾選是否列印補充詞；空正文不可匯出，無題目仍可匯出閱讀文本。異常提醒不阻擋下載。程式不替教師驗證文意或多語釋義。

### 目標詞與詞彙身份

可勾選清單是選定冊、課之所有文本部分生詞的去重聯集，同一生詞只顯示一次；來源文本僅作參考課文，切換同課來源文本不縮限可選清單。目標集合為教師實際勾選詞與手動目標詞的去重聯集，候選清單不等於已全選；初始勾選狀態仍待Q10。同詞來自兩種來源仍只有一個複現目標，不因輸入兩次而加倍最低次數。目標詞的來源應可追溯，以免把「教師要求練習」誤當作「教材已教過」。

手動新增不自動加入教材已學集合；若它原本已具有教材證據，仍按原證據判定，若沒有則不能只因被選作目標就免除超綱檢查。目標複現詞、補充引導詞及一般允許詞分開管理；同詞可有教師明確設定的不同用途，但三種身份不自動互相轉換，目標身份也與教師保留身份分開。一般引導詞也不因只用作發想就自動成為複現目標；同詞若由教師明確另選為目標，才依目標設定檢測，不自動刪除其引導用途。

### 次數、覆蓋與歧義的呈現

以目標詞 w、篇章 p 表示最低次數 m(w,p) 及確定詞彙出現次數 c(w,p)；預設 m(w,p)=1。統一次數讓教師批次設定，重要詞與個別篇章可調整，不用全篇總次數抵銷另一篇缺額。批次重設與已調整值如何互動見Q10。

- 次數表逐格顯示詞、篇章、確定實際次數、最低要求、可疑匹配及檢測狀態。
- 以 c(w,p) >= m(w,p) 判定時，只能使用確定的詞彙匹配；其他可疑匹配仍須標示，不能用來補足要求。若只能加入可疑匹配才達最低要求，必須標示待核對，不能自動宣稱確定達標。
- 不足量可用 max(m(w,p)-c(w,p),0) 表示「確定詞次相對最低要求的缺額」；有可疑匹配時，這不是教師已判定的最終缺額。
- 覆蓋仍回答哪些目標詞至少出現一次；最低次數達標回答哪些詞達到其設定要求。例如每詞要求2次時，每詞各出現1次可有全覆蓋，仍不符合最低次數。兩者不得混為同一指標。
- 詞彙單位計次已確認；複合詞邊界、詞形變體與歧義裁決方式尚待Q03/Q04/Q11，不能把指定字串強插進斷詞結果來製造達標。

### 第一階段提示詞與修訂邊界

提示詞精簡是減少重複與無關指令，不能省掉已確認的原課文、篇數、字數、創新要求、已學範圍、語法及核准人名。目標條件可用「詞｜篇1最低｜篇2最低｜篇3最低」簡表；只有實際要生成的篇數出現。文字格式示例只是文件建議，不是新增JSON schema或介面實作。

有引導詞才加入對應生成條件；沒有時省略整個引導詞條款。第一階段只處理閱讀文本，不放詳細題型、題數、選項或教師答案規格。生成時仍要求LLM自行核對條件，但不輸出逐項長篇自檢；省略報告不等於取消內部核對。可量化的正式檢測由Python執行，LLM自稱符合不能代替正式結果。第三階段原有閱讀測驗流程不因本次精簡而刪除。

Python逐篇檢測後，修訂提示詞優先針對未達標項目，列需要補足的篇、詞、最低要求、確定次數與缺額，避免不必要的全面重寫；不足清單不可把已達標詞再次列成不足。可保留必要原文上下文與生成條件，不把「優先修不足」解讀為禁止一切必要調整，也不藉此擅改教師要求。可疑匹配保留供教師核對，不當作確定缺漏或確定達標；其他疑似超綱、安全或人工教學提醒仍可在介面呈現，不自動塞入這份「複現不足修訂」提示詞。修訂不改原有目標設定；修訂後再檢測。

改動勾選、手動目標或最低次數後，原檢測結論不再代表目前設定，不能用舊結果確認目前版本；須重新檢測，再由教師人工審核與定稿。已定稿版本的歷史資料如何保留不在本次新增設計，不能以狀態失效為由刪除教師內容。

- 跨冊課保留非空草稿時，第二階段顯示「可能來自先前課次，請確認是否適用」提醒；即使草稿尚未檢測也會提醒。提醒不刪改草稿、不阻擋檢測或其他操作，不帶入前課核准。
- draft_lesson_id記錄草稿最後一次教師編輯時的課索引，on_change回呼僅更新該索引。非空草稿的記錄課次與目前idx不同時，提醒會在同一Session的rerun持續顯示；返回記錄課次或在目前課次重新編輯後，不再顯示跨課提醒。
- 這是來源可能性的提示，不是自動判定草稿適合當課，也不是強制教師確認的新增關卡。空草稿或同課來源切換不顯示此跨課提醒，原有設定變更失效規則保持。

## 十、第五階段第二批：逐篇目標詞檢測

本節記錄 codex/per-text-vocabulary-audit，以已合併PR #3的main（e436d7c2c92cfa92809860cdad5790aaea0ea0f4）為基礎。T11/T12/T15及N06–N11、N18在本批新增下列能力；教材、詞典、原始測試資料及target_settings模型不變。

### 逐篇辨識（技術格式，不是新增教學標準）

[vocabulary_audit.py](../vocabulary_audit.py) 的split_texts()保存原始行及標題位置：

- 單篇可直接貼正文；多篇需明確編號，優先使用既有prompt1格式「【文本一】標題」再換行貼正文。也支援數字「【文本1】」及獨立行「文本一：標題」，可帶Markdown標題前綴。
- 不以空白行或段落長度猜成多篇。缺某篇或該篇僅有標題時，那一篇詞次及缺額為未知空值、狀態待核對，不填0或宣稱達標；明確且有正文的其他篇仍各自檢測。
- 重複／逆序／超出設定的編號、無法辨識的標記、標題前未歸屬內容等，提醒格式不明，暫不給該組確定逐篇結果，不自動重排或合併。
- 標題行不是正文；說話者檢查排除已辨識的標題行，正文中的未知說話者照舊提醒。
- 尚未決定的其他格式與人工裁決流程仍屬Q11，保留教師手動修正原文後重檢；不替教師推定缺篇內容。

### 完整詞彙計數與可追溯候選

[app.py](../app.py) 的curriculum_word_index()由原audit的教材優先索引抽出，共用同一known／allow／text_evidence／grammar_evidence／核准人名集合與_curriculum_segment()。新per_text_target_audit()再將該結果與同一TOKENIZER的Jieba斷詞核對，兩者均沿用HMM=False。未把目標詞加入已學集合、字典或斷詞優先集合來強行湊詞。

audit_per_text()只在兩個結果都有相同起訖邊界的完整目標token時累加「確定出現次數」。這是可重現、保守的技術核對條件，不是宣告所有詞界爭議均已有教師共識。

- 子字串搜尋只定位候選，不直接當作正式詞次。候選落在較長詞內、跨多token或兩種結果邊界不一致時，只列「可疑出現次數」與證據。
- 每筆歧義包含目標詞、篇號、全貼文中的原始行號、行內起訖位置、原文、片段、教材優先斷詞、Jieba斷詞與原因。行號從1開始；位置為Python Unicode字元索引，從0開始，結束位置不含該字元，不是byte或UTF-16位置。
- 例如「咖啡豆」可能在教材優先結果拆成「咖啡／豆」，Jieba則為「咖啡豆」；內部的「咖啡」會列可疑而不是確定詞次。目標「台灣」若被拆字也不強制併回。
- 可疑數是候選位置數，可能有重疊，不是教師已認定的完整詞次。Q03/Q04/Q11的複合詞、詞形變體及人工裁決仍待教師確認，本批沒有新增「核准候選即加入詞典」流程。
- 含非單一片段格式的目標、設定缺格或斷詞無法與原文對齊時，顯示提醒及待核對，不悄悄補最低1次或以字串替代。
- 正文清理仍沿用cleanbody()；普通冒號前綴、標題樣式與罕見字等既有清理／字元範圍限制不在本批全面重寫。教師仍須核對輸入與證據；本檢測不等於語意／詞義正確性驗收。

### 表格、缺額與人工定稿

last_audit['逐篇複現']保存rows、ambiguities、issues及原始分篇記錄。逐格顯示「目標詞、篇章、最低次數、確定出現次數、可疑出現次數、確定不足量、狀態」，最低要求直接讀當前target_config.minimums[詞][篇號]，不得用其他篇的次數抵銷。

- 確定次數達最低值：達標，可疑候選不參與補足。
- 確定次數不足且有可疑候選：待核對，不把候選加入後自動報通過。
- 確定次數不足且無可疑候選：未達標。
- 缺篇、格式不明或不可計算：未知空值、待核對；未知不是0次。
- 「確定不足量」沿既有定義為max(最低要求－確定詞次,0)，即相對已確認詞次的缺額。有可疑時尚非教師裁決後的最終不足量，GUI明示此差別。
- 舊版全文彙總與子字串命中仍保留，但metric、表格與舊修訂提示明標參考，不作正式逐篇結果；LLM自稱通過不參與判定。
- 保留既有教師人工定稿流程；教師按定稿不會把表格中的未達標／待核對改成達標。未新增強制阻擋或人工裁決關卡。

### 結果同步與本批邊界

草稿編輯回呼在記錄課次外撤銷舊報告與approved；程式亦比對文本快照，防止非widget更新漏失效。檢測保存完整原始draft（含首尾空白），避免.strip()後與編輯原文不同而無法定稿。目標、各格最低值、篇數、參考來源、形式，以及影響斷詞的允許詞／核准人名改變，都必須重新檢測。保留草稿、歷史定稿、Word編輯內容及第一批的跨課提醒。

本批檢測對象為第二階段draft；第四階段Word編輯正文不自動回寫draft，該處的全面重檢D06仍待後續。沒有全面重寫命題、釋義、Word或提示詞；T14依正式缺額自動修訂、人工歧義裁決介面及T16條件衝突警示仍未實作，也未設定任意詞數／字數限制。
